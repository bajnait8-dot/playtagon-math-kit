# Эталонная копия старой модели

Немодифицированная копия `playtagon-dice/games/dice/server/model` на момент
переноса. Нужна только для сверки (`../verify-parity.ts`): новая модель сравнивается
с ней пооперационно.

Вне контракта §2.4. Платформа этот каталог не читает. `config.ts` здесь сохраняет
жёстко зашитые константы — именно то поведение, с которым сверяется новая модель.
